# articles/softbank-vs-rakuten/ 出典記録

対象記事：ソフトバンクから楽天モバイルへ｜スマホ・家族・自宅ネットの総額で比較
実装日：2026年10月5日

## 公開前に判断が必要な事項（最優先・先頭に記載）

### 1. ペイトク2の割引適用前の基本料金（10,538円）は、公式ページに直接の表示がなく、掲載された割引後価格から逆算して確認した

- https://www.softbank.jp/mobile/price_plan/data/paytoku2/ （2026年10月5日確認）には、「ペイトク2 税込10,538円/月（家族3人加入・ソフトバンク光/Air加入・PayPayカード ゴールドで支払いの場合）」という割引後価格の例しか明示的な表示が見当たらず、割引適用前の基本料金そのものを明記した一文は確認できなかった。
- 一方、同条件（家族3人＝新みんな家族割1,210円引、おうち割光セット1,100円引、PayPayカードゴールド割550円引、合計2,860円引）を [新みんな家族割](https://www.softbank.jp/mobile/price_plan/options/minna-kazokuwari-plus/)・[テイガク無制限](https://www.softbank.jp/mobile/price_plan/data/teigaku-museigen/) の各ページの数値に当てはめると、7,678円＋2,860円＝10,538円となり、本記事が採用する基本料金10,538円（税込）と一致した。
- 本記事では「10,538円」を基本料金として採用するが、公式ページの直接表示ではなく、複数ページの数値を合算して確認した金額であることをsources.mdに明記する。本文中では「ペイトク2」の基本料金を単独で大きく強調する構成を避け、常に割引後の参考例とセットで示す。

### 2. 新みんな家族割の「適用開始タイミング」「回線減少時の切替タイミング」は、月の途中で回線が減った場合の扱いまで確認できていない

- https://www.softbank.jp/mobile/price_plan/options/minna-kazokuwari-plus/ （2026年10月5日確認）には「割引は適用条件に合致した当該請求月から適用」「回線減少時は当該請求月の適用をもって割引を終了」という記載がある。
- ただし、月の途中でMNPにより回線が減った場合、その請求月（当月）はどちらの人数区分の割引額が適用されるのか（当月から新しい人数区分が適用されるのか、翌月からなのか）を一次資料だけで確定できなかった。本記事の③④の検算は、いずれも「切替が完了し、新しい人数区分が適用された後の月」どうしの比較として記載し、切替当月の扱いは断定しない。

### 3. SoftBank Airに「オプションパック（セット割）」に相当する携帯契約条件があるかどうかは確認できていない

- https://www.softbank.jp/internet/support/sbair/cancel/explanation/ （2026年10月5日確認）には「『おうち割 光セット』などセット割にお申し込みしている場合、割引などがなくなります」という記載があり、おうち割 光セット（スマホ側の割引）がAirでも対象になることは確認できる。
- 一方、SoftBank 光／光＋の「オプションパック（セット割）」（光BBユニット等をまとめた、携帯電話回線の契約を条件とする指定オプションの仕組み）に相当する、Air固有の指定オプション・携帯契約条件については、このFAQおよび関連ページで明記を確認できなかった。
- 本記事④では、オプションパック（セット割）の説明をSoftBank 光／光＋に限定し、Airについては「同様の仕組みがあるかは一次資料で確認できていません」と明記する（ymobile-vs-rakuten記事と同じ扱いを踏襲）。

### 4. 家族内の「請求代表者」変更・MNP時のSMS/メール持ち運びの扱いは、ソフトバンク・楽天モバイルいずれの一次資料でも確認できていない

- ソフトバンクの家族契約における請求代表者の変更方法、MNP時のメール持ち運び（@softbank.ne.jp等）の扱いについて、公式FAQで直接の記載を確認できなかった（https://www.softbank.jp/support/faq/view/10069 等は契約者名義変更の一般的な手続きのみ）。
- 楽天モバイルの契約者名義変更ページ（https://network.mobile.rakuten.co.jp/guide/contract-transfer/ 、2026年10月5日確認）も、第三者への契約譲渡の手続きのみを説明しており、「家族内の請求代表者だけを変更する」手続きの記載は見当たらなかった。
- 本記事⑥では、この2点を「公式窓口に直接確認が必要な未確認事項」として明記し、独自の手続き方法を創作しない。

### 新みんな家族割（回線数ごとの割引額、税込）
出典：https://www.softbank.jp/mobile/price_plan/options/minna-kazokuwari-plus/ （2026年10月5日確認）

| 対象プラン | 1人 | 2人 | 3人以上 |
|---|---|---|---|
| テイガク無制限 | 0円 | 660円 | 1,210円 |
| ペイトク2 | 0円 | 660円 | 1,210円 |
| ミニフィット2 | 0円 | 220円 | 550円 |

- 適用条件：同一の家族割引グループで対象データプランに加入中の回線が2回線以上。
- 家族の範囲：「同居していない家族も、遠くの親戚も、同居中のパートナーも、シェアハウスの仲間もみんな家族」と広く認められる。住所が同一なら本人確認書類のみ、住所が異なる場合は戸籍謄本等の追加書類（発行日から3カ月以内）が必要。
- カウント対象外：2023年5月17日以降に「電話番号・メールアドレスお預かりサービス」に加入した回線はカウント対象外。
- 適用タイミング：「割引は適用条件に合致した当該請求月から適用」「回線減少時は当該請求月の適用をもって割引を終了」（月中の切替時の詳細は上記「公開前に判断が必要な事項」2.参照）。

### おうち割 光セット・PayPayカード割
出典：https://www.softbank.jp/mobile/price_plan/data/teigaku-museigen/ 、https://www.softbank.jp/mobile/price_plan/data/paytoku2/ 、https://www.softbank.jp/support/faq/view/14699 （以上2026年10月5日確認）

- おうち割 光セット：1,100円/月引（テイガク無制限・ペイトク2共通、回線ごとに適用）。
- 適用条件：ソフトバンク／ワイモバイルの携帯電話回線の契約＋対象機種・対象プランの利用＋対象固定通信サービス（SoftBank 光、SoftBank 光＋、SoftBank Air、ケーブルライン、Yahoo! BB 光シティ等）の利用＋指定オプションの加入（SoftBank 光・光＋のみ必須。他の固定通信サービスでは不要な場合がある）。
- PayPayカード割：通常カード330円/月引、PayPayカードゴールド550円/月引（テイガク無制限・ペイトク2共通）。

### 指定オプション（セット割）とSoftBank光解約後の料金変化
出典：https://www.softbank.jp/support/faq/view/20657 、https://www.softbank.jp/support/faq/view/20658 （以上2026年10月5日確認）

- 指定オプション（オプションパック）の構成：光BBユニットレンタル＋Wi-Fiマルチパック＋電話サービス（BBフォン／ホワイト光電話／光電話(N)+BBフォンのいずれか1つ）。セット価格の例：月額550円〜。
- 適用条件：ソフトバンクまたはワイモバイルの携帯電話回線の契約が必須。
- 携帯電話を解約してもSoftBank 光／光＋自体の契約は継続できるが、「おうち割 光セット」解除後はオプション料金が通常価格に戻る。FAQの例：ホワイト光電話の基本プランが550円→2,115円。
- SoftBank Airの対応するセット割の仕組みは上記「公開前に判断が必要な事項」3.参照（一次資料で確認できていない）。

### 契約解除料（2026年7月新設）
出典：https://www.softbank.jp/mobile/info/personal/news/service/20260601a/ （2026年10月5日確認）

- 対象：2026年7月1日以降に新規契約またはのりかえ（MNP・番号移行）で加入した顧客。回線提供開始月から12カ月以内の解約で発生。
- 金額：解約時の料金プランにより385円〜1,100円（税込）。テイガク無制限等の音声プランは1,100円の区分に該当する例が示されている。
- ソフトバンクからワイモバイル・LINEMOへのりかえる場合は契約解除料が発生しない（楽天モバイルへのMNPはこの免除の対象外）。
- 2026年6月末以前から契約している顧客は、この新設の契約解除料の対象外。

### MNP手続き（ソフトバンク→楽天モバイル）
出典：https://network.mobile.rakuten.co.jp/guide/mnp/softbank/ （2026年10月5日確認）

- MNPワンストップ（推奨）：MNP予約番号の取得が不要で、楽天モバイル申し込み時に直接ソフトバンクへ転出を申請できる。
- 従来方式：ソフトバンク窓口（0800-100-5533 または My SoftBank）でMNP予約番号を取得してから楽天モバイルに申し込む。
- 必要なもの：本人確認書類、楽天会員ID・パスワード、クレジットカードまたは銀行口座情報。
- 名義：乗り換え元の名義と楽天モバイルでの契約名義が同一である必要がある。
- 旧回線を先に解約する必要はなく、MNP予約番号の有効期限満了日の午前10時に自動的に切り替わる。

### 楽天モバイルの料金・家族割・通話オプション
出典：https://network.mobile.rakuten.co.jp/fee/saikyo-plan/ 、https://network.mobile.rakuten.co.jp/fee/family/ 、https://network.mobile.rakuten.co.jp/service/standard-free-call/ （以上2026年10月5日確認）

| データ量 | 通常料金（税込） | 最強家族割適用時（税込） |
|---|---|---|
| 〜3GB | 1,078円 | 968円（最強家族割適用時） |
| 3GB超〜20GB | 2,178円 | 2,068円（最強家族割適用時） |
| 20GB超（無制限） | 3,278円 | 3,168円（最強家族割適用時） |

- 最強家族割：対象の家族全員が1人につき月110円（税込）引き。親等の制限なし、最大20回線まで。my 楽天モバイル（Rakuten Linkアプリ内）からグループを作成。書類不要でWeb完結。
- 適用タイミング：「グループに参加された家族全員に適用される」と案内されているが、具体的な適用開始日の詳細は別ページでの確認が必要とされており、本記事では「申し込み時点で最新の適用タイミングを確認してください」という案内に留め、独自に日付を断定しない。
- 国内通話：Rakuten Linkアプリ使用で原則無料（0570等の他社接続サービス、一部特番188は対象外）。標準の電話アプリはオプション未加入でも使えるが従量課金（22円/30秒）。15分（標準）通話かけ放題オプションは月額1,100円（税込）、初回1カ月無料、1回15分まで何度でも無料（対象外番号あり）。

### PayPayポイント還元（ペイトク2）
出典：https://www.softbank.jp/mobile/price_plan/data/paytoku2/ （2026年10月5日確認）

- 還元率：PayPayカードなし／通常カードは+5%（上限3,000円相当/月）、PayPayカードゴールド連携時は+10%（上限4,000円相当/月）。
- 対象外決済：通信料、医療機関・調剤薬局の支払い、交通系ICカード等へのチャージ。
- 本記事では、請求額の差額とPayPayポイント考慮後の参考差額を必ず別枠で表示し、ポイントを現金と同一視しない。

## 検算（二重検算スクリプトの実行結果）

検算スクリプト（Pythonで実行、assert文で内部整合性を確認済み）の出力を転記する。すべてのassertが通過している。

テイガク無制限(割引なし)=8,008円 / 楽天通常(20GB超)=3,278円 / 差額=4,730円

ケース2: 3人家族の1人・25GB・現行プラン+ネット割+通常カード

（ケース1の差額4,730円とは異なる）

ケース3: 3回線→1回線だけ楽天へ（3→2回線の割引再計算）
移行前(3回線): 5,368円×3=16,104円
移行後: 残る2線(2人家族割)=5,918円×2 + 楽天1線=3,278円 = 15,114円
世帯差: 990円（楽天側が得）
検算: 残る1線あたり増加550円×2=1,100円 / 移行した本人の節約2,090円 → 2,090-1,100=990 ✓

ケース4: 2回線→1回線だけ楽天へ（2→1回線の割引変化）
移行前(2回線): 5,918円×2=11,836円
移行後: 残る1線(家族割消滅)=6,578円 + 楽天1線=3,278円 = 9,856円
世帯差: 1,980円（楽天側が得）
ケース3の差額(990円)とケース4の差額(1,980円)は異なる（割引ステップが660→1,210の550円刻みと0→660の660円刻みで非対称なため）

ケース5: 3回線全員が楽天へ（3GB/20GB/25GB）
移行前(3回線・全員テイガク無制限・3人家族割+光+通常カード): 5,368円×3=16,104円

この場合の世帯差=9,900円-1,565円=8,335円（それでも楽天が得）

ケース6: ペイトク2・PayPayポイント考慮
請求額のみの比較: ペイトク2(通常カード割のみ)=10,208円 / 楽天通常=3,278円 / 請求額差=6,930円
対象決済0円の月: 還元0pt→実質負担10,208円（請求額差と同じ）

## 採用しなかった・未確認のまま扱った情報

- ソフトバンク「新みんな家族割」の月中切替時の適用タイミング（上記1.参照）→独自の断定をせず、切替完了後の月どうしの比較に限定。

- SoftBank Airのオプションパック相当の仕組み（上記3.参照）→SoftBank 光／光＋に限定して説明し、Airは対象外と明記。
- 家族内の請求代表者変更・MNP時のメール持ち運びの扱い（上記4.参照）→公式窓口への確認を促す案内に留める。
- 楽天最強家族割の適用開始の具体的な日時→独自に計算せず、申込時点での最新確認を案内。
- 紹介特典の新番号（乗り換え以外）ケースの13,000pt→本記事はMNP（乗り換え）前提のため14,000ptを中心に案内し、新番号に触れる場合はrakuten-recontract記事と同様、金額を断定しない表現にする。
