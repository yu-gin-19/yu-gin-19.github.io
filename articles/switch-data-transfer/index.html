楽天モバイルに乗り換えると何が変わる？
電話番号・LINE・写真・アプリ・キャリアメールを解説

結論から言うと、「今のスマホをそのまま使う」場合は通信会社を変えるだけなので、本体の写真やアプリが回線変更を理由に消えることはありません。一方、「機種変更も同時にする」場合は、LINEや写真・連絡先などを新しい端末へ移すための準備が必要です。キャリアメールは、どちらの場合でも元のキャリアのアドレスがそのままでは使えなくなる点に注意してください。この記事では、それぞれのケースで何が変わり、何を事前に準備すればよいかを整理します。

最初に結論が分かる比較表

まずは自分がどちらに当てはまるかを確認してください。

ケースA 今のスマホをそのまま使う 通信会社だけを楽天モバイルに変える場合。端末を初期化する作業ではありません。 詳しく見る → ケースB 乗り換えと同時に機種変更する 新しい端末へLINEや写真・連絡先などを移す準備が必要です。 詳しく見る →
結論

「乗り換える」＝「スマホが初期化される」ではありません。今のスマホを使い続けるなら本体のデータはそのまま残ります。データ移行が必要になるのは、端末も買い替える場合です。この2つを混同しないことが、この記事でいちばん大切なポイントです。

電話番号はどうなるか

電話番号の扱いは、ケースA・ケースBどちらでも同じ考え方です。

📱
MNPで乗り換える場合
今の電話番号をそのまま楽天モバイルに引き継げます
🆕
新規契約を選ぶ場合
電話番号は新しい番号になります
📋
MNPワンストップの対象は乗り換え元の会社によって異なる
対応会社かどうかは楽天モバイル公式サイトで確認してください

MNPワンストップに対応した会社からの乗り換えであれば、MNP予約番号を自分で取得する必要はありません。ただし、店舗での申し込みは対象外で、Web申し込み限定です。対応会社の一覧は変更される可能性があるため、申し込み前に公式サイトで確認してください。

POINT 電話番号の引き継ぎ申請から開通までの具体的な手順は、乗り換え手順の解説記事で4ステップに分けて説明しています。

LINEはどうなるか

LINEについては、「回線だけ変える」か「端末も変える」かで必要な準備が変わります。LINEアカウントの引き継ぎと、トーク履歴のバックアップは別のものです。この2つを混同すると、トーク履歴だけ消えてしまうことがあります。

ケースA：同じ端末で回線だけ変更する場合

端末そのものは変わらないため、LINEアプリ内のデータは基本的にそのまま残ります。ただし、電話番号が変わる場合（新規契約を選んだ場合など）は、LINEの設定から電話番号の変更手続きが必要です。SMS認証が使えないケースでは、Facebook連携などの代替認証方法を確認しておくと安心です。

ケースB：新しい端末へ変更する場合

新しい端末でLINEを使うには、旧端末で「アカウント引き継ぎ設定」をオンにしたうえで、一定時間内に新端末で引き継ぎ操作を行います。トーク履歴は自動的には移らないため、事前にバックアップが必要です。iPhoneはiCloud、AndroidはGoogleドライブにバックアップする仕組みです。

事前に確認しておきたいこと
  • LINEに登録しているパスワードとメールアドレス（またはID）
  • トーク履歴のバックアップ（iCloud／Googleドライブ）を直近で取っているか
  • バックアップ用PINコード（6桁）を設定しているか
  • iPhoneとAndroidを行き来する機種変更かどうか
OSをまたぐ機種変更の注意点
  • iPhone⇔Android間の機種変更では、通常のバックアップ機能だけではトーク履歴を復元できません
  • 事前にバックアップ用PIN（6桁）を設定しておくと、直近のトーク履歴をOSをまたいでも引き継げます
  • PINコードを設定していない場合、トーク履歴が復元できないことがあります

「LINEは絶対に消えません」とは言い切れません。引き継ぎ設定とバックアップを事前に済ませたうえで機種変更することが、トーク履歴を失わないための基本です。詳しい手順はLINEアカウント引き継ぎガイドとトーク履歴バックアップガイド（いずれもLINE公式）で確認できます。

写真・動画・連絡先

ケースAでは、通信会社を変えるだけで端末を初期化する作業ではないため、本体に保存された写真・動画・連絡先が回線変更を理由に削除されることはありません。

ケースBで機種変更する場合は、次のような方法でデータを移します。

🍎
iPhone→iPhone：クイックスタート
新旧の端末を近づけ、Wi-Fi・Bluetoothでデータを転送します（Apple公式）
🤖
Android→iPhone：「iOSに移行」アプリ
連絡先・写真・メッセージ履歴などを転送できます（Apple公式）
🔄
Android→Android：デバイスの切り替え
新旧端末をペア設定し、ワイヤレスまたはケーブルで移行します（Google公式）
📲
iPhone→Android：データの移行
Googleアカウント・写真・連絡先などを移行できます。iCloudにのみ保存された写真や有料アプリの購入履歴は移行対象外です（Google公式）

写真・連絡先は「本体保存」と「クラウド同期」の2種類があります。クラウド同期（iCloud写真、Googleフォトのバックアップなど）がオンになっていれば、機種変更後もクラウド経由でデータを確認できます。同期がオフの場合は本体データのみが頼りになるため、機種変更前に必ずバックアップの有無を確認してください。

POINT 旧端末を初期化・返却するのは、新端末でバックアップが正しく反映されていることを確認してからにしてください。

アプリとアプリ内データ

「アプリ本体」と「アプリ内のアカウント・データ」は別物です。アプリを新端末にインストールし直しても、多くの場合はログインすればデータを引き継げます。ただし、次のようなアプリは個別の確認が必要です。

🏦
銀行・証券アプリ
機種変更時に再認証やアプリの再登録が必要な場合があります
🔐
認証アプリ（二段階認証など）
機種変更前に引き継ぎコードの発行が必要なアプリが多くあります
💳
QRコード決済
ログインIDと登録済み電話番号・メールを事前に確認してください
🚃
モバイルSuicaなどの電子マネー
機種変更時は「機種変更手続き」を事前に行わないと残高を引き継げない場合があります
🎮
ゲーム
機種変更前に引き継ぎ用のIDやコードの発行が必要な場合があります
📶
キャリア決済で支払っているサービス
乗り換え後は使えなくなるため、事前に別の支払方法へ変更が必要です
個別サービスの移行方法は変わりやすい
  • 各サービスの引き継ぎ手順は仕様変更が多く、この記事では一般化しすぎない範囲で紹介しています
  • 金融系・電子マネー系のアプリは、必ず各サービスの公式サイト・公式アプリ内の案内で最新の手順を確認してください
  • 機種変更前の「引き継ぎ設定」を忘れると、サポートに問い合わせても復元できない場合があります

キャリアメール

楽天モバイルへ乗り換えると、ドコモ・au・ソフトバンクのキャリアメール（@docomo.ne.jp、@ezweb.ne.jp／@au.com、@softbank.ne.jpなど）はそのままでは使えなくなります。「解約後も無料で残る」ものではないため注意してください。

各社とも、有料の「メールアドレス持ち運びサービス」を用意しています。申込期限・料金は会社ごとに異なります。

申し込み前に確認したいこと
  • ネットバンキングやクレジットカードなど、ログインIDやパスワード再設定先にキャリアメールを使っていないか
  • キャリアメール宛に届く認証コードに依存しているサービスがないか
  • 持ち運びサービスを使わない場合、長期的にはGmailやiCloudメールなど別のメールアドレスへ移す選択肢もある

回線変更で影響を受けるサービス

キャリアメール以外にも、回線変更にともなって確認が必要な項目があります。

  • キャリア決済（コンテンツ利用料などの支払いに使っていないか）
  • 家族割（家族の契約に影響がないか）
  • 光回線・ホームルーターとのセット割（割引が外れないか）
  • 留守番電話サービスなど旧キャリアのオプション
  • 旧キャリアの会員アプリ・ポイントサービス
  • 端末補償サービス
  • 端末代金の分割払い
端末残債は解約と同時に消えるわけではない
  • 端末代金を分割払い中の場合、回線を解約しても支払い方法は変わらず分割請求が続きます
  • 残っている金額の確認は、契約しているクレジットカード会社などへの確認が必要です
  • 端末購入プログラムを利用している場合は、製品返却の要否・条件が異なることがあるため、契約中の各社公式サイトで確認してください

旧キャリアの解約

MNPで乗り換える場合、楽天モバイル側でのMNP転入が完了すると、元のキャリアの回線は自動的に解約されます。ご自身で先に解約する必要はありません。

自分で先に解約してはいけません
  • MNP転入が完了する前に旧キャリアを自分で解約すると、電話番号を引き継げなくなります
  • MNP転入の完了メールが届くまでは、旧キャリアの解約手続きを行わないでください
  • 解約月の料金・請求タイミングは契約先によって異なるため、旧キャリアのマイページ等で確認してください

MNP転入の具体的な手順（申し込みから開通までの流れ）は、乗り換え手順の解説記事で詳しく説明しています。

よくある質問

正しく引き継ぎ手続きを行えば、LINEアカウントは消えません。ただし、電話番号が変わる場合や機種変更を伴う場合は、事前にアカウント引き継ぎ設定とトーク履歴のバックアップが必要です。手続きをしないまま初期化すると、トーク履歴などのデータが復元できなくなる場合があります。
通信会社を変えるだけで端末を初期化する作業ではないため、本体に保存された写真が回線変更だけを理由に消えることはありません。ただし、万一のトラブルに備えて、クラウドや別の場所へのバックアップは日頃からしておくと安心です。
MNP（電話番号そのままの乗り換え）を選べば、今の電話番号を引き継げます。新規契約を選んだ場合は新しい電話番号になります。
楽天モバイルへ乗り換えると、元のキャリアのメールアドレス（@docomo.ne.jpなど）はそのままでは使えなくなります。各社が提供する持ち運びサービス（有料・要申込）を使えば引き続き利用できますが、料金・申込期限は会社ごとに異なるため、事前に公式サイトで確認してください。
LINEアカウント、トーク履歴、写真・動画、連絡先、各種アプリのログイン情報などを新しい端末へ移行する準備が必要です。OS（iPhone・Android）や乗り換え元によって使う機能が異なるため、事前にバックアップを済ませてから機種変更することをおすすめします。
MNPの場合、転入が完了すると元のキャリアの回線は自動的に解約されます。ご自身で先に解約する必要はなく、むしろ開通前に自分で解約すると番号が引き継げなくなるため注意してください。ただし、キャリア決済・端末の分割払い残債・セット割などは自動的に精算されるとは限らないため、別途確認が必要です。
